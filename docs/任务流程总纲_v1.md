**② 物料摆好后，检测立刻正常**（60 条消息 / 60 条非空）：

| 观测项 | 结果 |
|---|---|
| 每帧框数（阈值 0.25） | **2~45 个**，大量跨类重复（`LK/SLZ/SMT` 互相叠） |

| 帧率（相机 60fps 输入） | Sub 60.9 / Smart 37.4 FPS（pre 3 + infer 10 + post 14 ≈ 27ms） |

**③ 板端框坐标空间 = 原图 640×480，无系统性偏移（关键结论）**
把板端框与本地 torch 框逐一配对（IoU≥0.5）统计：

| 假设 | 平均 dx | 平均 dy | 结论 |
|---|---|---|---|
| 板端框已是原图坐标 | **-0.6 px** | **-1.2 px** | ✅ 成立 |
| 板端框是 672 拉伸坐标（需映回） | 明显偏差 | y 偏差可达 0.714 倍 | ❌ 排除 |

单框实证：板端 `(275,202)-(359,279)` vs 本地 letterbox-640 `(276,205)-(360,279)` → **误差 1~3 px**。板端置信度 0.98 甚至高于本地 0.82（BPU 量化后略有差异）。
→ **下游节点拿到的 ROI 可以直接当原图像素用，不需要任何缩放**。

**④ `ai_msgs` 字段坑**：本版本 `Target` 消息是 `type` + **`rois`**，**没有 `tracks`**。写订阅节点必须按 `rois` 解析，否则回调抛 `AttributeError` 直接把节点打挂。

**⑤ 拉伸预处理确实有害（量化证据）**：同一帧本地模拟 672 拉伸 → 52 个框，640 letterbox → 23 个框，且拉伸模式出现 `[527,0,638,0]` 这种**高度为 0 的退化框**。→ 再次支持「重建 640×480 bin」。

**⑥ 板端已做的改动**：`/root/vision_ws/yolov5_best_config.json` 的 `score_threshold` 由 `0.25` 改为 **`0.50`**（原文件备份为 `yolov5_best_config.025.bak`）。0.25 时一帧几十个重叠误检，下游根本无法用。

## 附录 A：NHWC raw 后处理参考实现

> 前置：输入必须 letterbox，输出必须按 letterbox 的 `ratio / pad` 逆变换，**不能用简单 `sx/sy`**。

```python
import numpy as np

# 与 best.pt 完全一致（勿改）
ANCHORS = np.array([
    [[10, 13], [16, 30], [33, 23]],
    [[30, 61], [62, 45], [59, 119]],
    [[116, 90], [156, 198], [373, 326]],
], dtype=np.float32)                       # (3 scale, 3 anchor, 2)
STRIDES = np.array([8, 16, 32], dtype=np.float32)


def _sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))


def decode_nhwc(outputs, nc=7, conf_thres=0.25, iou_thres=0.45):
    """
    outputs: BPU 输出的 3 个 NHWC raw 张量，形状 (1, ny, nx, 3*(5+nc))
    返回: (boxes_xyxy_in_input_px, scores, class_ids)
    """
    boxes, scores, cls_ids = [], [], []
    for si, out in enumerate(outputs):
        out = np.asarray(out)
        if out.ndim == 4:
            out = out[0]
        ny, nx, ch = out.shape
        assert ch == 3 * (5 + nc), f'通道数不符: {ch} != {3 * (5 + nc)}'

        g = out.reshape(ny, nx, 3, 5 + nc).astype(np.float32)
        grid_x, grid_y = np.meshgrid(np.arange(nx, dtype=np.float32),
                                     np.arange(ny, dtype=np.float32))
        grid = np.stack((grid_x, grid_y), axis=-1)          # (ny,nx,2)

        xy = (_sigmoid(g[..., 0:2]) * 2.0 - 0.5 + grid[..., None, :]) * STRIDES[si]
        wh = (_sigmoid(g[..., 2:4]) * 2.0) ** 2 * ANCHORS[si]
        obj = _sigmoid(g[..., 4:5])
        cls = _sigmoid(g[..., 5:])

        conf = obj * cls.max(axis=-1, keepdims=True)
        keep = conf[..., 0] > conf_thres
        if not keep.any():
            continue

        c = xy[keep]                                        # (N,2) center
        s = wh[keep]                                        # (N,2) size
        boxes.append(np.concatenate([c - s / 2, c + s / 2], axis=-1))
        scores.append(conf[keep][:, 0])
        cls_ids.append(cls[keep].argmax(axis=-1))

    if not boxes:
        return np.zeros((0, 4), np.float32), np.zeros((0,), np.float32), np.zeros((0,), np.int32)

    boxes = np.concatenate(boxes)
    scores = np.concatenate(scores)
    cls_ids = np.concatenate(cls_ids)
    keep = nms_numpy(boxes, scores, iou_thres)
    return boxes[keep], scores[keep], cls_ids[keep]


def nms_numpy(boxes, scores, iou_thres):
    order = scores.argsort()[::-1]
    keep = []
    while order.size:
        i = order[0]
        keep.append(i)
        xx1 = np.maximum(boxes[i, 0], boxes[order[1:], 0])
        yy1 = np.maximum(boxes[i, 1], boxes[order[1:], 1])
        xx2 = np.minimum(boxes[i, 2], boxes[order[1:], 2])
        yy2 = np.minimum(boxes[i, 3], boxes[order[1:], 3])
        w = np.maximum(0.0, xx2 - xx1)
        h = np.maximum(0.0, yy2 - yy1)
        iou = w * h / ((boxes[i, 2] - boxes[i, 0]) * (boxes[i, 3] - boxes[i, 1])
                       + (boxes[order[1:], 2] - boxes[order[1:], 0])
                       * (boxes[order[1:], 3] - boxes[order[1:], 1]) - w * h + 1e-9)
        order = order[np.where(iou <= iou_thres)[0] + 1]
    return np.array(keep, dtype=np.int64)
```

**逆 letterbox**：

```python
def unletterbox(boxes, ratio, pad_x, pad_y):
    out = boxes.copy()
    out[:, [0, 2]] = (out[:, [0, 2]] - pad_x) / ratio
    out[:, [1, 3]] = (out[:, [1, 3]] - pad_y) / ratio
    return out
```
